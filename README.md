# Engineering portfolio — Umang Patel

Single-page portfolio site. Plain HTML and CSS, no build step.

## Publishing with GitHub Pages

1. Create a public repo on GitHub. Naming it `<your-username>.github.io` gives you
   `https://<your-username>.github.io`; any other name gives you
   `https://<your-username>.github.io/<repo-name>/`.
2. Upload everything in this folder, keeping the structure:
   - `index.html`
   - `img/` (all images)
   - `Umang_Patel_Engineering_Portfolio.pdf`
3. Repo **Settings → Pages → Source: Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
4. Wait a minute or two, then load the URL.

## Updating

Replace the file and commit. The URL stays the same, so links you have already
sent keep working.
